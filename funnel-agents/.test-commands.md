# Quick Test Command Reference

## NPM Commands

### Primary
```bash
npm test              # Run all tests
npm run test:unit     # Unit tests only
npm run test:e2e      # E2E tests (API Gateway)
npm run test:cov      # All tests with coverage report
```

### Development
```bash
npm run test:watch    # Watch mode (auto-rerun on changes)
npm run test:debug    # Debug mode (attach debugger)
npm run test:affected # Only test affected projects
```

### Specific Test Types
```bash
npm run test:services     # All service tests
npm run test:integration  # Integration tests only
npm run test:e2e:all      # All E2E test suites
```

### CI
```bash
npm run test:ci      # CI mode (strict, no watch)
npm run test:cov     # Coverage for CI/CD pipelines
```

## Make Commands

### Primary
```bash
make test            # All tests
make test-unit       # Unit tests only
make test-e2e        # E2E tests
make test-cov        # With coverage report
```

### Service-Specific
```bash
make test-auth           # Auth service
make test-crm            # CRM service
make test-campaigns      # Campaigns service
make test-automations    # Automations service
make test-reports        # Reports service
```

### Development
```bash
make test-watch          # Watch mode
make test-services       # All services
make test-integration    # Integration tests
make test-debug          # Debug mode
```

### Utilities
```bash
make test-clean          # Clean test cache and coverage
make test-affected       # Only affected tests
make test-ci             # CI mode
```

## Direct NX Commands

### Run Specific Service
```bash
npx nx test auth-service
npx nx test crm-service
npx nx test campaigns-service
npx nx test automations-service
npx nx test reports-service
```

### Run Specific Test File
```bash
npm test -- leads.service.spec.ts
npm test -- --testNamePattern="should create"
```

### Coverage
```bash
npx nx test auth-service --coverage
npx nx run-many --target=test --all --coverage
```

## Common Workflows

### Before Commit
```bash
npm run test:unit && npm run lint
```

### Before Push
```bash
npm run test:cov && npm run format:check
```

### Before PR
```bash
npm run test:cov
npm run test:e2e
npm run lint
npm run format:check
```

### Debug Specific Test
```bash
npm test -- --testNamePattern="should qualify" --watch
```

### Check Coverage
```bash
npm run test:cov
open coverage/index.html
```

## Environment Variables

### Test Database
```bash
DATABASE_URL=sqlite::memory: npm test
DATABASE_URL=postgresql://test:test@localhost:5432/test npm run test:integration
```

### Test Secrets
```bash
JWT_SECRET=test-secret npm test
JWT_REFRESH_SECRET=test-refresh-secret npm test
```

## Quick Examples

### Run Tests for One File
```bash
npm test -- apps/auth-service/src/auth.service.spec.ts
```

### Run Tests Matching Pattern
```bash
npm test -- --testNamePattern="should register"
```

### Run Tests in Debug Mode
```bash
npm run test:debug
# Then attach debugger to Node process
```

### Run Tests with Verbose Output
```bash
npm test -- --verbose
```

### Run Tests Without Cache
```bash
npm test -- --no-cache
```

### Run Single Test Suite
```bash
npm test -- --testNamePattern="LeadsService"
```

## Useful Flags

```bash
--watch              # Watch mode
--coverage           # Generate coverage
--verbose            # Detailed output
--silent             # Minimal output
--no-cache           # Clear Jest cache
--maxWorkers=4       # Limit parallel workers
--runInBand          # Run serially
--bail               # Stop on first failure
--testPathPattern    # Filter by file path
--testNamePattern    # Filter by test name
```

## Troubleshooting

### Clear Cache
```bash
make test-clean
# or
npm test -- --clearCache
```

### Port In Use
```bash
lsof -i :3000
kill -9 <PID>
```

### Memory Issues
```bash
NODE_OPTIONS=--max_old_space_size=4096 npm test
```

### Timeout Issues
```bash
npm test -- --testTimeout=10000
```
