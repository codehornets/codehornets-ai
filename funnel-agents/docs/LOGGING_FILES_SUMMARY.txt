USAGE COMMANDS
--------------

Check installation:
  make logs-check

Migrate a service:
  make logs-migrate SERVICE=auth-service

View logs:
  make logs-view
  make logs-view-service SERVICE=auth-service

Search logs:
  make logs-search PATTERN="error"
  make logs-search PATTERN="correlation" SERVICE=auth-service

View documentation:
  make logs-docs
  cat LOGGING_QUICK_START.md
  cat LOGGING_IMPLEMENTATION_REPORT.md

INTEGRATION STEPS
-----------------

For each service:
1. Update app.module.ts with EnhancedLoggingModule
2. Update main.ts to use EnhancedLoggerService
3. Replace AppLoggerService with EnhancedLoggerService
4. Replace console.log with logger methods
5. Add setContext() in service constructors
6. Add LOG_LEVEL and LOG_FORMAT to environment
7. Update docker-compose.yml with logging config
8. Test correlation ID tracking

See LOGGING_QUICK_START.md for detailed steps.
