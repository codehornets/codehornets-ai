## Lock Flow Diagram

```
Request to Execute Task "task-123"
         │
         ▼
┌────────────────────────────────────────┐
│ 1. Acquire Lock                        │
│    Key: scheduler:task:task-123        │
│    TTL: 60000ms                        │
│    LockId: pid-timestamp-random        │
└──────────┬─────────────────────────────┘
           │
           ▼
      ┌────────┐     Yes     ┌─────────────────────┐
      │ Lock   │─────────────→│ 2. Execute Task     │
      │ Acquired? │           │    - Create exec    │
      └────────┘              │    - Dispatch       │
           │                  │    - Update status  │
           │ No               └──────────┬──────────┘
           ▼                             │
      ┌─────────────────┐                │
      │ 3. Skip Task    │                │
      │    Log: Already │                │
      │    executing    │                │
      └─────────────────┘                │
                                         ▼
                              ┌──────────────────────┐
                              │ 4. Release Lock      │
                              │    (in finally)      │
                              └──────────────────────┘
```

## Component Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                        Scheduler Service                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                    CronJobsService                        │  │

│  │                                                           │  │
│  │  @Cron('* * * * *')                                      │  │
│  │  async checkDueTasks() {                                 │  │
│  │    🔒 Lock: scheduler:check-due-tasks                    │  │
│  │    if (!acquired) skip                                   │  │
│  │    ... check and execute tasks                           │  │
│  │  }                                                        │  │
│  │                                                           │  │
│  │  async executeTask(task) {                               │  │
│  │    🔒 Lock: scheduler:task:{taskId}                      │  │

│  └───────────────────────────────────────────────────────────┘  │
```

## Lock State Machine

```
                    ┌─────────┐
                    │  Start  │
                    └────┬────┘
                         │
                         ▼
              ┌──────────────────┐
              │ Request Lock     │
              │ SET NX PX        │
              └────┬────┬────────┘
                   │    │
         Success   │    │  Failure
                   │    │
         ┌─────────▼    ▼─────────┐
         │                        │
    ┌────▼─────┐           ┌──────▼───────┐
    │ ACQUIRED │           │   REJECTED   │
    │          │           │              │
    │ LockId:  │           │ Return null  │
    │ xyz123   │           └──────────────┘
    └────┬─────┘                  │
         │                        │
         │                        │
    ┌────▼──────────┐             │
    │  Do Work      │             │
    │               │             │
    │  Auto-extend  │             │
    │  if needed    │             │
    └────┬──────────┘             │
         │                        │
         ▼                        │
    ┌────────────┐                │
    │  Release   │                │
    │  DEL (Lua) │                │
    └────┬───────┘                │
         │                        │
         └────────┬───────────────┘
                  │
                  ▼
            ┌──────────┐
            │   Done   │
            └──────────┘
```

```
             │

             │
Instance 3: ─┼────[Acquire]─✗─[Skip]──────────────────────────
             │
             └─ Only Instance 1 gets lock
```

## Error Handling Flow

```
Lock Acquisition
      │
      ▼
┌──────────────┐
│ Redis Check  │
└──────┬───────┘
       │
       ├─ Available ──→ [Acquire] ──→ [Execute]
       │
       ├─ Locked ─────→ [Skip] ──────→ [Log & Return]
       │
       └─ Error ──────→ [Log Error] ─→ [Fallback Mode]
                           │
                           └─ Continue without locking
                              (Single instance mode)
```

```
       │  │ M  │  │ S  │ │

```

Legend:
🔒 = Lock protected operation
✓ = Lock acquired
✗ = Lock rejected
M = Master
S = Slave
