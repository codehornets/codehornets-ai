================================================================================
                              KEY FINDINGS
================================================================================

✓ /proc/PID/fd/0 does NOT work
  Reason: Writes to display, not input queue

✓ socat is the solution
  Why: Multipurpose relay for PTY forwarding

✓ Unix socket is optimal for IPC
  Performance: 1-5ms latency, no network overhead

✓ Always use --init flag
  Reason: Critical for PID 1 signal handling

✓ Window resize won't auto-sync
  Reason: socat relay breaks SIGWINCH propagation
  Workaround: Manual stty command available
